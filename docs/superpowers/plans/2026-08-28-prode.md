# PRODE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users predict exact scores of real matches and pick a tournament champion, earning XP/Fichas (and, only for champion picks, a small amount of Balón de Oro) once results are confirmed server-side against live FotMob data.

**Architecture:** Two new Supabase tables (`prode_picks`, `prode_champion_picks`) with client-facing `SECURITY DEFINER` RPCs for submitting picks (RLS + expiry checks protect them) and separate `service_role`-only RPCs for settlement. A new Deno Edge Function (`settle-prode`) — triggered by `pg_cron` — fetches live results directly from FotMob (same host the app's existing `/fotmob` proxy points to) and calls the settlement RPCs. Frontend: a new "Pronósticos" tab on the existing `CompetitionPage.vue`, backed by a small `src/services/prode.js` service and two new Vue components.

**Tech Stack:** Vue 3 (Composition API, matching `CompetitionPage.vue`), Supabase Postgres + `pg_cron`/`pg_net`, Supabase Edge Functions (Deno), no automated test runner in this project — every task's "test" step is a manual verification via the Supabase MCP tools or the browser, matching how the rest of this codebase is validated.

**Spec:** `docs/superpowers/specs/2026-08-28-prode-design.md`

## Global Constraints

- Supabase project id for all MCP tool calls: `pihoijedkkapkilylavn` (project "FULVO").
- Match score points: exact score = 3 pts (+30 XP / +15 Fichas), correct winner/draw only = 1 pt (+10 XP / +5 Fichas), wrong = 0.
- Champion pick reward (only on a correct pick): +500 XP, +300 Fichas, **+20 Balón de Oro** (documented exception to the "Balón de Oro is purchase-only" rule — the opportunity is extremely rare, once per multi-year tournament, picked blind before a ball is kicked).
- Match predictions apply to any competition with `status: 'live'` in `src/services/competitions.js`. Champion picks apply only to competitions with `bracket: true` there.
- `award_xp()` and `unlock_achievement()` (already in the DB) use `auth.uid()` internally and CANNOT be called from server-side/service-role code for an arbitrary user — confirmed by reading their live definitions. All settlement writes go through new `service_role`-only RPCs that take an explicit `p_uid`/target user parameter and write directly to `xp_events` / `user_achievements`.
- New achievement codes: `prode_5_correct`, `prode_10_correct`, `prode_perfect_matchday`, `prode_champion`.
- FotMob's real playoff data shape (verified live against the 2026 World Cup, id 77): `overview.json` → `pageProps.playoff.rounds[]`, each `{ stage, matchups: [{ homeTeamId, awayTeamId, winner, homeScore, awayScore, ... }] }`. The final's `matchups[0].winner` is `null`/absent until decided, then holds the winning team's numeric id.
- FotMob fixtures shape (already used by `src/services/fotmob.js` `getAllMatches`): each match has `id`, `round`/`roundName`, `home.id`/`home.name`, `away.id`/`away.name`, `status.finished`, `status.scoreStr` (e.g. `"2 - 1"`, home first).
- Every FotMob HTTP call from server-side code (Edge Function) must send `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36` — FotMob's proxy config in `vite.config.js`/`vercel.json` already does this for browser requests; the Edge Function talks to `fotmob.com` directly and must set it itself.

- [ ] **Step 1: Write `supabase/prode.sql` with the table + RPC**

```sql
-- ════════════════════════════════════════════════════════════
--  PRODE — pronósticos sobre partidos reales
-- ════════════════════════════════════════════════════════════
--  Ver docs/superpowers/specs/2026-08-28-prode-design.md para el diseño completo.
--  Correr en el SQL Editor de Supabase (o vía apply_migration).
-- ════════════════════════════════════════════════════════════

CREATE TABLE IF NOT EXISTS public.prode_picks (
  id             UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id        UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  competition    TEXT NOT NULL,
  match_id       TEXT NOT NULL,
  home_team      TEXT NOT NULL,
  away_team      TEXT NOT NULL,
  home_pick      SMALLINT NOT NULL,
  away_pick      SMALLINT NOT NULL,
  kickoff_at     TIMESTAMPTZ NOT NULL,
  round          TEXT,
  points         SMALLINT,
  xp_awarded     SMALLINT,
  fichas_awarded SMALLINT,
  settled_at     TIMESTAMPTZ,
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (user_id, match_id)
);

CREATE INDEX IF NOT EXISTS idx_prode_picks_settlement
  ON public.prode_picks (competition, settled_at)
  WHERE settled_at IS NULL;

ALTER TABLE public.prode_picks ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "prode_picks read own" ON public.prode_picks;
CREATE POLICY "prode_picks read own" ON public.prode_picks
  FOR SELECT USING (auth.uid() = user_id);
-- Sin policy de INSERT/UPDATE: todo escritura pasa por submit_prode_pick / settle_prode_match_pick (SECURITY DEFINER).

-- RPC cliente: carga o actualiza un pronóstico mientras el partido no arrancó.
CREATE OR REPLACE FUNCTION public.submit_prode_pick(
  p_competition TEXT,
  p_match_id    TEXT,
  p_home_team   TEXT,
  p_away_team   TEXT,
  p_home_pick   SMALLINT,
  p_away_pick   SMALLINT,
  p_kickoff_at  TIMESTAMPTZ,
  p_round       TEXT DEFAULT NULL
)
RETURNS JSON
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  uid UUID := auth.uid();
BEGIN
  IF uid IS NULL THEN
    RETURN json_build_object('ok', false, 'error', 'auth');
  END IF;
  IF p_kickoff_at <= now() THEN
    RETURN json_build_object('ok', false, 'error', 'locked');
  END IF;
  IF p_home_pick IS NULL OR p_away_pick IS NULL
     OR p_home_pick < 0 OR p_away_pick < 0
     OR p_home_pick > 20 OR p_away_pick > 20 THEN
    RETURN json_build_object('ok', false, 'error', 'invalid_score');
  END IF;

  INSERT INTO public.prode_picks
    (user_id, competition, match_id, home_team, away_team, home_pick, away_pick, kickoff_at, round)
  VALUES
    (uid, p_competition, p_match_id, p_home_team, p_away_team, p_home_pick, p_away_pick, p_kickoff_at, p_round)
  ON CONFLICT (user_id, match_id) DO UPDATE SET
    home_pick  = EXCLUDED.home_pick,
    away_pick  = EXCLUDED.away_pick,
    kickoff_at = EXCLUDED.kickoff_at,
    round      = EXCLUDED.round,
    updated_at = now()
  WHERE public.prode_picks.kickoff_at > now() AND public.prode_picks.settled_at IS NULL;

  RETURN json_build_object('ok', true);
END$$;

REVOKE ALL ON FUNCTION public.submit_prode_pick(TEXT, TEXT, TEXT, TEXT, SMALLINT, SMALLINT, TIMESTAMPTZ, TEXT) FROM PUBLIC, anon;
GRANT EXECUTE ON FUNCTION public.submit_prode_pick(TEXT, TEXT, TEXT, TEXT, SMALLINT, SMALLINT, TIMESTAMPTZ, TEXT) TO authenticated;
```

  uid UUID := auth.uid();

    RETURN json_build_object('ok', false, 'error', 'auth');

- [ ] **Step 1: Append the settlement RPCs**

```sql
-- Igual que unlock_achievement() ya existente, pero con UID explícito para uso
-- server-side (unlock_achievement() usa auth.uid() y no sirve para un cron).
CREATE OR REPLACE FUNCTION public.unlock_achievement_for_user(
  p_uid  UUID,
  p_code TEXT,
  p_meta JSONB DEFAULT '{}'::jsonb
)
RETURNS BOOLEAN
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_ach_id   UUID;
  v_points   INTEGER := 0;
  v_inserted BOOLEAN := false;
BEGIN
  IF p_uid IS NULL THEN RETURN false; END IF;

  SELECT id, points INTO v_ach_id, v_points FROM public.achievements WHERE code = p_code;
  IF v_ach_id IS NULL THEN RETURN false; END IF;

  INSERT INTO public.user_achievements (user_id, achievement_id, metadata)
  VALUES (p_uid, v_ach_id, COALESCE(p_meta, '{}'::jsonb))
  ON CONFLICT (user_id, achievement_id) DO NOTHING;

  GET DIAGNOSTICS v_inserted = ROW_COUNT;

  IF v_inserted THEN
    INSERT INTO public.xp_events (user_id, game_id, amount, reason, session_id, meta)
    VALUES (p_uid, NULL, v_points, 'achievement', NULL, jsonb_build_object('achievement', p_code));
  END IF;

  RETURN v_inserted;
END$$;

REVOKE ALL ON FUNCTION public.unlock_achievement_for_user(UUID, TEXT, JSONB) FROM PUBLIC, anon, authenticated;
GRANT EXECUTE ON FUNCTION public.unlock_achievement_for_user(UUID, TEXT, JSONB) TO service_role;

-- Liquida UN pronóstico de partido ya finalizado. Idempotente: si ya estaba
-- liquidado (settled_at not null), no hace nada (UPDATE ... WHERE no matchea).
CREATE OR REPLACE FUNCTION public.settle_prode_match_pick(
  p_pick_id UUID,
  p_points  SMALLINT,
  p_xp      INTEGER,
  p_fichas  INTEGER
)
RETURNS VOID
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_uid           UUID;
  v_competition   TEXT;
  v_round         TEXT;
  v_total_correct INTEGER;
  v_round_total   INTEGER;
  v_round_perfect INTEGER;
BEGIN
  UPDATE public.prode_picks
  SET points = p_points, xp_awarded = p_xp, fichas_awarded = p_fichas, settled_at = now(), updated_at = now()
  WHERE id = p_pick_id AND settled_at IS NULL
  RETURNING user_id, competition, round INTO v_uid, v_competition, v_round;

  IF NOT FOUND THEN RETURN; END IF;

  IF p_xp > 0 THEN
    INSERT INTO public.xp_events (user_id, game_id, amount, reason, session_id, meta)
    VALUES (v_uid, NULL, p_xp, 'prode_match', NULL, jsonb_build_object('pick_id', p_pick_id));
  END IF;

  IF p_fichas > 0 THEN
    PERFORM public.award_fichas(v_uid, p_fichas, 'prode_match', jsonb_build_object('pick_id', p_pick_id));
  END IF;

  IF p_points > 0 THEN
    SELECT count(*) INTO v_total_correct FROM public.prode_picks WHERE user_id = v_uid AND points > 0;
    IF v_total_correct >= 5  THEN PERFORM public.unlock_achievement_for_user(v_uid, 'prode_5_correct', '{}'::jsonb); END IF;
    IF v_total_correct >= 10 THEN PERFORM public.unlock_achievement_for_user(v_uid, 'prode_10_correct', '{}'::jsonb); END IF;

    IF v_round IS NOT NULL THEN
      SELECT count(*), count(*) FILTER (WHERE points = 3)
        INTO v_round_total, v_round_perfect
        FROM public.prode_picks
        WHERE user_id = v_uid AND competition = v_competition AND round = v_round AND settled_at IS NOT NULL;
      IF v_round_total >= 3 AND v_round_total = v_round_perfect THEN
        PERFORM public.unlock_achievement_for_user(v_uid, 'prode_perfect_matchday', jsonb_build_object('round', v_round));
      END IF;
    END IF;
  END IF;
END$$;

REVOKE ALL ON FUNCTION public.settle_prode_match_pick(UUID, SMALLINT, INTEGER, INTEGER) FROM PUBLIC, anon, authenticated;
GRANT EXECUTE ON FUNCTION public.settle_prode_match_pick(UUID, SMALLINT, INTEGER, INTEGER) TO service_role;

-- Liquida el pick de campeón de UN usuario para UNA competición. Idempotente
-- igual que la anterior.
CREATE OR REPLACE FUNCTION public.settle_prode_champion_pick(
  p_user_id     UUID,
  p_competition TEXT,
  p_won         BOOLEAN,
  p_xp          INTEGER,
  p_fichas      INTEGER,
  p_balones     INTEGER
)
RETURNS VOID
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = public
AS $$
BEGIN
  UPDATE public.prode_champion_picks
  SET result          = CASE WHEN p_won THEN 'win' ELSE 'loss' END,
      xp_awarded       = CASE WHEN p_won THEN p_xp ELSE 0 END,
      fichas_awarded   = CASE WHEN p_won THEN p_fichas ELSE 0 END,
      balones_awarded  = CASE WHEN p_won THEN p_balones ELSE 0 END,
      settled_at       = now()
  WHERE user_id = p_user_id AND competition = p_competition AND settled_at IS NULL;

  IF NOT FOUND THEN RETURN; END IF;

  IF p_won THEN
    IF p_xp > 0 THEN
      INSERT INTO public.xp_events (user_id, game_id, amount, reason, session_id, meta)
      VALUES (p_user_id, NULL, p_xp, 'prode_champion', NULL, jsonb_build_object('competition', p_competition));
    END IF;
    IF p_fichas > 0 THEN
      PERFORM public.award_fichas(p_user_id, p_fichas, 'prode_champion', jsonb_build_object('competition', p_competition));
    END IF;
    IF p_balones > 0 THEN
      PERFORM public.add_balones(p_user_id, p_balones, 'prode_champion', jsonb_build_object('competition', p_competition));
    END IF;
    PERFORM public.unlock_achievement_for_user(p_user_id, 'prode_champion', jsonb_build_object('competition', p_competition));
  END IF;
END$$;

REVOKE ALL ON FUNCTION public.settle_prode_champion_pick(UUID, TEXT, BOOLEAN, INTEGER, INTEGER, INTEGER) FROM PUBLIC, anon, authenticated;
GRANT EXECUTE ON FUNCTION public.settle_prode_champion_pick(UUID, TEXT, BOOLEAN, INTEGER, INTEGER, INTEGER) TO service_role;
```

 * SERVICIO PRODE
 *
 * Capa fina sobre las RPCs de supabase/prode.sql. Los partidos y equipos NO se
 * vuelven a pedir acá: CompetitionPage.vue ya tiene `leagueData.allMatches`
 * cargado (getLeagueOverview), se lo pasa como prop a los componentes de PRODE.
 * Este servicio solo sabe leer/escribir picks y calcular la recompensa a mostrar
 * (los montos reales los otorga settle_prode_match_pick / settle_prode_champion_pick
 * server-side — estas constantes son solo para el preview visual, deben coincidir
 * con las que usa supabase/functions/settle-prode/index.ts).

import { supabase } from './supabase'

export const PRODE_REWARDS = {
  exact: { points: 3, xp: 30, fichas: 15 },
  winner: { points: 1, xp: 10, fichas: 5 },
  champion: { xp: 500, fichas: 300, balones: 20 },
}

/** Equipos únicos (id + nombre) a partir de la lista de partidos ya cargada. */
export function deriveTeams(matches) {
  const map = new Map()
  for (const m of matches || []) {
    if (m.homeTeamId != null) map.set(String(m.homeTeamId), m.homeTeam)
    if (m.awayTeamId != null) map.set(String(m.awayTeamId), m.awayTeam)
  }
  return Array.from(map, ([id, name]) => ({ id, name }))
}

/** Kickoff del primer partido del torneo (ISO string), o null si no hay partidos. */
export function firstKickoff(matches) {
  const times = (matches || []).map(m => m.time).filter(Boolean).sort()
  return times[0] || null
}

export async function submitPick({ competition, matchId, homeTeam, awayTeam, homePick, awayPick, kickoffAt, round }) {
  const { data, error } = await supabase.rpc('submit_prode_pick', {
    p_competition: competition, p_match_id: String(matchId),
    p_home_team: homeTeam, p_away_team: awayTeam,
    p_home_pick: homePick, p_away_pick: awayPick,
    p_kickoff_at: kickoffAt, p_round: round || null,
  })
  if (error) return { ok: false, error: error.message }
  return data
}

export async function submitChampionPick({ competition, teamId, teamName, lockedAt }) {
  const { data, error } = await supabase.rpc('submit_prode_champion_pick', {
    p_competition: competition, p_team_id: String(teamId), p_team_name: teamName, p_locked_at: lockedAt,
  })
  if (error) return { ok: false, error: error.message }
  return data
}

/** Picks propios de una competición, indexados por match_id para lookup O(1) en la UI. */
export async function getMyPicks(competition) {
  const { data, error } = await supabase
    .from('prode_picks')
    .select('id, match_id, home_pick, away_pick, kickoff_at, points, xp_awarded, fichas_awarded, settled_at')
    .eq('competition', competition)
  if (error) { console.warn('[prode] getMyPicks error:', error.message); return {} }
  const byMatch = {}
  for (const row of data || []) byMatch[row.match_id] = row
  return byMatch
}

export async function getMyChampionPick(competition) {
  const { data, error } = await supabase
    .from('prode_champion_picks')
    .select('team_id, team_name, locked_at, result, xp_awarded, fichas_awarded, balones_awarded, settled_at')
    .eq('competition', competition)
    .maybeSingle()
  if (error) { console.warn('[prode] getMyChampionPick error:', error.message); return null }
  return data
}

export function isChampionPickEnabled(comp) {
  return !!comp?.bracket
}

    const html = await res.text()
    const m = html.match(/"buildId"\s*:\s*"([^"]+)"/)
    cachedBuildId = m ? m[1] : null
  } catch (_e) {
    cachedBuildId = null
  }
  return cachedBuildId
}

async function fetchFixtures(leagueId: number): Promise<Fixture[] | null> {
  const buildId = await getBuildId()
  if (!buildId) return null
  try {
    const res = await fetch(`https://www.fotmob.com/_next/data/${buildId}/en/leagues/${leagueId}/fixtures.json`, { headers: { 'User-Agent': UA } })
    if (!res.ok) return null
    const raw = await res.json()
    const data = raw.pageProps || raw
    const allMatches = data.fixtures?.allMatches || data.allMatches || []
    return allMatches.map((m: any) => ({
      id: String(m.id),
      round: m.roundName ?? null,
      homeId: String(m.home.id),
      awayId: String(m.away.id),
      finished: !!m.status.finished,
      scoreStr: m.status.scoreStr as string | undefined,
    }))
  } catch (_e) {
    return null
  }
}

/** ID del equipo campeón, o null si la final todavía no se jugó / FotMob no respondió. */
async function fetchChampionTeamId(leagueId: number): Promise<string | null> {
  const buildId = await getBuildId()
  if (!buildId) return null
  try {
    const res = await fetch(`https://www.fotmob.com/_next/data/${buildId}/en/leagues/${leagueId}/overview.json`, { headers: { 'User-Agent': UA } })
    if (!res.ok) return null
    const raw = await res.json()
    const data = raw.pageProps || raw
    const finalRound = (data.playoff?.rounds || []).find((r: any) => r.stage === 'final')
    const winner = finalRound?.matchups?.[0]?.winner
    return winner != null ? String(winner) : null
  } catch (_e) {
    return null
  }
}

function parseScore(scoreStr: string | undefined): { home: number; away: number } | null {
  if (!scoreStr) return null
  const m = scoreStr.match(/^(\d+)\s*-\s*(\d+)$/)
  if (!m) return null
  return { home: parseInt(m[1], 10), away: parseInt(m[2], 10) }
}

serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: corsHeaders })

  try {
    const cronSecret = Deno.env.get('CRON_SECRET')
    if (cronSecret && req.headers.get('x-goaldemy-cron-secret') !== cronSecret) {
      return new Response(JSON.stringify({ error: 'No autorizado' }), {
        status: 401, headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      })
    }

    const supabase = createClient(
      Deno.env.get('SUPABASE_URL')!,
      Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!,
    )

    let matchesSettled = 0
    let championsSettled = 0

    for (const [slug, leagueId] of Object.entries(ALL_COMPETITIONS)) {
      const { count: pendingMatchPicks } = await supabase
        .from('prode_picks').select('id', { count: 'exact', head: true })
        .eq('competition', slug).is('settled_at', null)

      const championEnabled = slug in CHAMPION_COMPETITIONS
      let pendingChampionPicks = 0
      if (championEnabled) {
        const { count } = await supabase
          .from('prode_champion_picks').select('user_id', { count: 'exact', head: true })
          .eq('competition', slug).is('settled_at', null)
        pendingChampionPicks = count || 0
      }

      if (!pendingMatchPicks && !pendingChampionPicks) continue

      if (pendingMatchPicks) {
        const fixtures = await fetchFixtures(leagueId)
        if (fixtures) {
          const { data: picks } = await supabase
            .from('prode_picks').select('id, match_id, home_pick, away_pick')
            .eq('competition', slug).is('settled_at', null)

          for (const pick of picks || []) {
            const fixture = fixtures.find(f => f.id === pick.match_id)
            if (!fixture || !fixture.finished) continue
            const real = parseScore(fixture.scoreStr)
            if (!real) continue

            let points = 0
            if (pick.home_pick === real.home && pick.away_pick === real.away) {
              points = 3
            } else if (Math.sign(pick.home_pick - pick.away_pick) === Math.sign(real.home - real.away)) {
              points = 1
            }
            const xp = points === 3 ? 30 : points === 1 ? 10 : 0
            const fichas = points === 3 ? 15 : points === 1 ? 5 : 0

            const { error } = await supabase.rpc('settle_prode_match_pick', {
              p_pick_id: pick.id, p_points: points, p_xp: xp, p_fichas: fichas,
            })
            if (!error) matchesSettled++
          }
        }
      }

      if (pendingChampionPicks) {
        const championId = await fetchChampionTeamId(leagueId)
        if (championId) {
          const { data: championPicks } = await supabase
            .from('prode_champion_picks').select('user_id, team_id')
            .eq('competition', slug).is('settled_at', null)

          for (const cp of championPicks || []) {
            const won = cp.team_id === championId
            const { error } = await supabase.rpc('settle_prode_champion_pick', {
              p_user_id: cp.user_id, p_competition: slug, p_won: won,
              p_xp: 500, p_fichas: 300, p_balones: 20,
            })
            if (!error) championsSettled++
          }
        }
      }
    }

    return new Response(JSON.stringify({ ok: true, matchesSettled, championsSettled }), {
      headers: { ...corsHeaders, 'Content-Type': 'application/json' },
    })
  } catch (e) {
    console.error('settle-prode error:', e)
    return new Response(JSON.stringify({ error: e.message || 'Error interno' }), {
      status: 500, headers: { ...corsHeaders, 'Content-Type': 'application/json' },
    })
  }
})
